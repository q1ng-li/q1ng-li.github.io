鸿蒙应用概述

DevEco Studio下载链接

https://developer.huawei.com/consumer/cn/deveco-studio/

app架构

利用ai生成了一个简单的鸿蒙app demo

  • AppScope目录由DevEco Studio自动生成

  • entry目录包含应用的主入口等关键代码和资源，存放着entry模块的文件

​ src/main/ets 存放编写的 ArkTS 源代码

​ src/main/module.json5 模块配置文件

  • hvigor目录包含构建工具的特定配置信息，用于调整构建的行为和参数，它帮助管理构建过程，确保应用能够正确地编译、打包和部署

1.分析一个app 应该先重点关注 src/main/module.json5 模块配置文件

UIAbility组件是系统调度的基本单元，为应用提供绘制界面的窗口，具体在entry->src->main->module.json5->abilities

从上面的配置可以看到，这个组件名称为EntryAbility，”exported”: true 说明该组件对外部公开，意味着其它应用可以调用，启动这个UIAbility；skills 声明了 action.system.home 和 entity.system.home，代表这是应用的“主页/入口Activity ；srcEntry UIAbility组件的入口路径。

2.打开 UIAbility组件的入口路径

简单分析一下源码，首先创建了一个类 EntryAbility，onWindowStageCreate函数创建了一个窗口，内部完成了两件事，一是通过 windowStage.loadContent('pages/Index') 绑定并渲染了主页 UI；二是调用了 restoreTasks(this.context) 恢复本地持久化数据，onForeground 与 onBackground（前后台切换）

启动pages/Index文件

  • 选择模拟器或真机设备

在 DevEco Studio 顶部菜单栏选择 Tools -> Device Manager。在弹出的面板中启动本 地模拟器（Local Emulator）

  • 观察 HiLog 输出

在启动模拟器时发现原本vibe coding还是存在1%的问题，不过经过该工具的ai修复，现在成功在模拟机上打开了应用
