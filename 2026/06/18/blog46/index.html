什么是fastjson

简单来说，fastjson是一个java库，由alibaba发布。其可以将 Java 对象转换为 JSON 格式，当然它也可以将 JSON 字符串转换为 Java 对象，来分析一个简单的demo

以上这个demo有一个小插曲，对于private类型的字段，外部是不能直接访问的，所以我们需要满足JavaBean规范。疑惑在于demo中fastjson没有显示调用getName()和getAge(),原因是Fastjson源码中通过反射来处理JavaBean规范（ 一个类只要遵守 JavaBean 规范，就能被这些框架自动处理）

对于以上的demo,我们可以直接将json字符串转换为对应的Java对象在于json字符串的字段与类的属性要一致。如果二者有出入，这里也有解决办法，可以使用@JSONField注解来指定Java类的属性和JSON字段之间的映射关系

什么是@type

@type是fastjson中的一个特殊注解，用于标识JSON字符串中的某个属性是一个Java对象的类型。具体来说，当fastjson从JSON字符串反序列化为Java对象时，如果JSON字符串中包含@type属性，fastjson会根据该属性的值来确定反序列化后的Java对象的类型

什么是JNDI

JNDI（Java Naming and Directory Interface，Java 命名和目录接口）是 Java 官方提供的一种 API 规范

尝试先配置一个JNDI环境，将其跑在tomcat上更加方便.

（1）首先下载一个tomcat,https://tomcat.apache.org/,访问该目录下的bin目录文件夹下的startup.bat,就可以成功启动一个tomcat服务。接着可以对配置文件context.xml 或 web.xml加入数据源

（2）在新建的项目下配置tomcat服务；接着在Deployment页中加上该项目的构建后的产物（xxxx:war exploded）。在Project Structure,在Modules先给该项目配置web,然后在项目的Dependencies处添加tomcat;接着在Artifacts处配置相关路径。完成后build project

（3）tips:在Project Structure中选择Artifacts要选择Web Application: Exploded以及配置相关pom.xml

什么是RMI

RMI由三部分组成

  • RMI Registry 注册表：服务实例将被注册表注册到特定的名称中（可以理解为电话簿）

  • RMI Server 服务端

  • RMI Client 客户端：客户端通过查询注册表来获取对应名称的对象引用，以及该对象实现的接口

RMI指的是远程方法调用（Remote Method Invocation）是Java平台提供的一种机制，可以实现在不同Java虚拟机之间进行方法调用。在JVM之间通信时，RMI对远程对象和非远程对象的处理方式是不一样的，它并没有直接把远程对象复制一份传递给客户端，而是传递了一个远程对象的Stub，Stub基本上相当于是远程对象的引用或者代理（Java RMI使用到了代理模式）。Stub对开发者是透明的，客户端可以像调用本地方法一样直接通过它来调用远程方法。Stub中包含了远程对象的定位信息，如Socket端口、服务端主机地址等等，并实现了远程调用过程中具体的底层网络通信细节，即具体传输过程如下

①客户端通过远程连接 Registry 获取存根(Stub)，存根(Stub)中包含了远程对象的定位信息，如Socket端口、服务端主机地址等等，并实 现了远程调用过程中具体的底层网络通信细节。

②由于存根(Stub) 是客户端的代理类，所以客户端可以调用Stub上的方法

③Stub远程连接到服务器，提交对应的参数

④骨架(Skeleton) 收到数据并对其进行反序列化，然后将发送给我们的Server

⑤Server执行之后将结果进行打包，传输给Client
