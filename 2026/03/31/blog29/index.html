Java类加载

不过在学习之前，我们应该先理解java类加载。 Java类加载器(Java Classloader)是Java运行时环境(Java Runtime Environment)的一部分，负责动态加载Java类到Java虚拟机的内存空间中，用于加载系统、网络或者其他来源的类文件。

类加载分类

这里以我的jdk1.8.0_65为例

引导类加载器(BootstrapClassLoader)

Bootstrap ClassLoader 通常是由 C/C++ 代码实现的，不继承java.lang.ClassLoader类，主要负责加载核心Java库，即在/jre/lib/rt.jar目录当中的类

扩展类加载器(ExtensionsClassLoader)

由sun.misc.Launcher$ExtClassLoader类实现

继承自 Java 体系内的抽象基类 java.lang.ClassLoader，用来加载/jre/lib/ext目录下的类，或者是在java.ext.dirs中指明的目录。

应用类加载器(AppClassLoader)

由sun.misc.Launcher$AppClassLoader实现，用来加载用户使用的第三方依赖

自定义类加载器(UserDefineClassLoader)

自定义类加载器(UserDefineClassLoader)，通过继承java.lang.ClassLoader类重写findClass()方法来实现自定义类加载器

CLassLoader类核心方法

除了上述BootstrapClassLoader，其他类加载器都是继承了CLassLoader类，我们就一起看看其类的核心方法

loadClass：加载指定的java类

loadClass方法中，一开始先调用findLoadedClass,如果没有就会触发双亲委派机制，使用父加载器调用loadClass(String)方法，如果父加载器为null，就触发调用引导类加载器；如果还是没有找到，就会调用findClass()去找

最终如果找到了，那么就会调用 resolveClass()来处理类

findCLass：查找指定的Java类

findLoadedClass：查找JVM已经加载过的类

defineClass：定义一个Java类，将字节码解析成虚拟机识别的Class对象。往往和findClass()方法配合使用。

defineClass是java类加载机制中的核心方法，主要用于将字节数组转换成JVM中的Class对象。(字节码本质就是一个字节数组bite[])。在ClassLoader.java中defineClass这个方法是protect类型，需要使用反射

resolveClass：链接指定Java类

  1. 继承ClassLoader类
  2. 重写findClass方法
  3. 在findClass方法中调用defineClass方法
