    远程桌面连接

    查询远程桌面控制 (RDP) 3389 端口是否启用 shell netstat -ano | findstr 3389

    输出为空行，说明未启用，使用此命令开启 RDP

    shell REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal" "Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f

    尝试远程连接，似乎win7这台主机开了防火墙

    shell netsh advfirewall show allprofiles 查看防火墙状态

    从上图可看到防火墙状态为打开且拦截了入站数据

    执行 shell netsh advfirewall set allprofiles state off 命令尝试关闭服务器的防火墙 (或者执行此命令单独放行 RDP 流量 netsh advfirewall firewall add rule name="Allow Remote Desktop" action=allow dir=in protocol=TCP localport=3389)

    #注册表开启3389端口

    REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal” “Server /v fDenyTSConnections /t REG_DWORD /d 00000000 /f

    #添加防火墙规则

    netsh advfirewall firewall add rule name=”Open 3389” dir=in action=allow protocol=TCP localport=3389

    #关闭防火墙

    netsh firewall set opmode disable #winsows server 2003 之前

    netsh advfirewall set allprofiles state off #winsows server 2003 之后

    win + R mstsc.exe 打开远程桌面连接

    连接后修改密码为 Admin123! 成功连接

    哈希传递攻击(PTH)拿下域控

    在域环境中，利用哈希传递攻击的渗透方式往往是这样的：

    1. 获得一台域主机的权限，Dump 内存获得该主机的用户密码 Hash 值；
    2. 通过哈希传递攻击尝试登录其他主机；
    3. 继续搜集 Hash 并尝试远程登录，直到获得域管理员账户 Hash，登录域控，最终成功控制整个域。

    前期我们通过内网渗透获取到 GOD 密码凭证

    cs哈希传递攻击

    抓到了一个名叫 Administrator 的账号，它属于一个叫 GOD 的域。在域环境中，GOD\Administrator 通常就是整个域的最高管理员（域管）；认证这笔凭据的服务器叫 OWA。这台 OWA 大概率就是这个域的域控（DC）

    psexec 利用域管理员账户 Hash login一下 监听器选 smb

    成功拿下域控

    通过这个靶场学到了一些知识点，在此纪录一下

    域环境

    本次测试主要对象就是域环境，讲明几个概念

    1.判断是否存在域环境

    说明存在域环境,其dns服务器极有可能是域控

    1. 查看域环境存在哪些主机

    哈希传递攻击

    正如本靶场而言，通过机器上抓取到这个域管凭据拿到域管的 NTLM 哈希，攻击者利用这个凭据，通过哈希传递（PTH）合法地登录域控。对于凭据就需要Mimikatz工具

    NTLM（NT LAN Manager）是微软从 Windows NT 时代就引入的一套古老的网络认证协议。当你在 Windows 里设置密码（比如 root@2026）时，系统为了安全，绝对不会把明文直接存在硬盘上。它会把你的明文密码经过 MD4 算法 进行单向加密，生成一串 32 位的十六进制字符串。
