    学习笔记

    序

    nodejs学习一下，感觉一些机制和python挺像的，可以类比学习

    day1

    使用 require 指令来加载和引入模块(类似import)

    当然，假如外部有个user.js

    函数

    箭头函数

    关键字async，await处理异步操作

    模块类型

    类比于python,Node.js支持以下几种模块

    内置模块、用户第三方模块、第三方模块

    不过不像python3，builtins内的模块不需要导入可以直接使用；而Nodejs的模块都需要request导入

    类似的，python中dir()可以查看属性列表；Nodejs中Object.keys() / Object.getOwnPropertyNames()

    Node.js 全局对象（global）

    类比于python3的builtins，全局对象内部的属性不需要导入就可以使用

    __filename 表示当前正在执行的脚本的文件名

    __dirname 表示当前执行脚本所在的目录。

    console 用于提供控制台标准输出

    process.env 环境变量对象 、process.argv 脚本名+用户参数 process.env.NODE_ENV读取字典中的NODE_ENV

    • 内置模块（常用）

    child_process 子进程管理 exec,execFile,spawn,fork

    如果给 option = { silent: true } 赋值为对象字面量，那么就会自动继承Object.prototype

    Object.prototype是一个原型对象 ，option是一个实例对象。那么option.__proto__ = option.constructor.prototype = Object.prototype

    http 创建http服务 createServer, request, get (工厂模式，不直接让你 new，而是通过一个函数来帮你创建对象)

    event 事件处理 EventEmitter, on, emit, once(类模式，直接暴露类的定义，必须 new来创建实例)

    监听data事件

    os homedir, hostname (只提供系统信息查询)

    day2

    原型链

    my_func()是一个函数对象，my_func.__proto__ 指向 [Function (anonymous)] 这是所有函数对象的原型

    my_func.__proto__.__proto__ 指向 [Object: null prototype]，原型链顶端

    如果过滤了 __proto__ 可以用 prototype替代 这两者的区别在于调用的对象不同， __proto__ 可以被几乎所有对象访问，而 prototype 存在于函数。因此对于一个对象的实例，只能通过__proto__访问

    JavaScript 规定，每个函数都有一个prototype属性，指向一个对象

    typeof my_func.prototype ; // object

    上面的例子似乎将 __proto__ 和 prototype 连接在一起，不过想要熟练运用还得明白这两者差异

    prototype 函数拥有，是函数的属性

    __proto__几乎所有对象都有，其作用是告诉JS引擎，如果’我’身上找不到某个属性，顺着 __proto__ 往上找

    hacker.__proto__ 指向的是其构造函数的 prototype 属性 即等于 Person.prototype

    Person.__proto__指向的是其构造函数的 prototype 属性，js中函数的构造函数是内置的Function ,即等于 Function.prototype

    如果想用prototype绕过，必须允许 typeof source[key] === ‘object’ || typeof obj === ‘function’
