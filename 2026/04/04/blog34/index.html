一个简单的shiro涉及的内容还真不少。用过一些shiro反序列化工具的师傅们都知道，往往attack一个shiro系统都是用到CommonsBeanutils链，那么这个链到底有什么奇幻的地方，我们一起来探索一下

PriorityQueue利用链

java.util.PriorityQueue是 Java 集合框架中的一个无界优先队列实现，它基于堆（Heap）数据结构，确保每次取出的元素都是当前队列中优先级最高（或最小）的元素

java.util.PriorityQueue 是⼀个有⾃⼰readObject()⽅法的类

既然提到java.util.PriorityQueue，那就不能忘了org.apache.commons.collections4.comparators.TransformingComparator ，在该类中compare调用transform()方法

原因是java.util.PriorityQueue#readObject() 中调⽤了heapify() ⽅ 法,而我们跟进heapify()方法，该方法调用了siftDown(),继续跟进siftDown()中调用了siftDownUsingComparator(),最终siftDownUsingComparator()调用了comparator.compare(),成功与上面的形成完美的闭环

而transform()方法的利用我们已经很熟悉了，cc1链中有其使用

Apache Commons Beanutils

Apache Commons Beanutils 是 Apache Commons 工具集下的另一个项目，它提供了对普通Java类对 象（也称为JavaBean）的一些操作方法。

比如，Cat是一个最简单的JavaBean类

对于Cat这个类。包含一个私有属性name,以及读取和设置这个属性的两个方法，又称为getter和setter。
