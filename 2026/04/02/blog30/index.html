过滤()

  • 利用装饰器 @
  • 利用魔术方法，例如 enum.EnumMeta.__getitem_

@是语法糖，叠加时从下往上执行

装饰器的作用是在不修改原来函数/类的代码情况下，为其添加额外功能。其本质也是一个函数，接收参数，返回函数

class x: pass 中的x作为一个接收参数 首先执行 s2(x)，s2是一个匿名函数，接收参数返回whoami,然后这个返回结果作为参数被system调用，即最终system(‘whoami’)

(这里我在想，如果我这个匿名函数不需要参数，不就不需要class x: pass，但装饰器这个函数必须要有参数作为输入)

对于魔术方法

在标准库中寻找一个模块，这个模块包含某个类和这个类的实例。EnumMeta在创建Enum时在类自定义阶段就自动将类属性转换为单例实例

其中 {}.__doc__[2] + {}.__doc__[15] + {}.__doc__[0]表示 cmd

enum.EnumMeta.__getitem__ = system , 其中enum.EnumMeta是元类，如果通过修改元类的
