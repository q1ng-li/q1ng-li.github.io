    靶场

    序

    最近作为实习生入职了绿盟科技。作为刚开始加入这个公司的一员，还有很多需要适应，不说了，开始练习这个靶场

    简介

    Ubuntu系统，利用桥接模式，那么主机就可以访问这个靶场（攻防靶场）

    step1 Search

    访问发现是一个智慧小区管理系统

    先进行端口扫描，发现没有效果

    换了个命令发现成功了，发现四个端口

    dddd 是一款用 Go 语言编写的高效复合型安全工具。它的核心功能通常包括：

    1. 资产收集： 集成 Fofa、Hunter 等空间测绘 API 拉取目标。
    2. 指纹识别： 自动识别目标站点的技术栈、CMS 及组件框架。
    3. 漏洞探测： 兼容 Nuclei 的 PoC 格式，可以直接挂载漏洞脚本进行大批量扫描。
    4. 端口与子域名枚举： 辅助完成目标的外网面侦察。

    核心漏洞发现

    • Redis 未授权访问 (Redis Unauthorized)
    • PostgreSQL 数据库弱口令 用户名 postgres，密码 postgres
    • SSH 服务弱口令 用户名 postgres，密码 postgres
